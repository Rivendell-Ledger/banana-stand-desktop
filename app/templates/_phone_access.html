Before you turn it on

  • 1Restart after saving. Quit The Banana Stand from the tray icon (right-click → Quit), then open it again. Saving the toggle does not rebind the running server, and closing the window only hides it in the tray.
  • 2Answer the Windows firewall prompt with Yes. The first time it listens, Windows asks whether to allow BananaStand to communicate on networks. Choose Yes and tick Private networks. If you missed it or answered No, open Windows Security → Firewall & network protection → Allow an app through firewall, tick BananaStand on Private, or run this in an admin PowerShell: 
    New-NetFirewallRule -DisplayName "Banana Stand" -Direction Inbound -Program "$env:LOCALAPPDATA\Programs\BananaStand\BananaStand.exe" -Action Allow -Profile Private
  • 3Check what it is listening on (PowerShell): 
    Get-NetTCPConnection -LocalPort {{ port }} -State Listen | Select-Object LocalAddress,LocalPort
    0.0.0.0 means the network is open. 127.0.0.1 means it is still this computer only — go back to step 1.
  • 4Check the Wi-Fi is marked Private (PowerShell): 
    Get-NetConnectionProfile
    If it says Public, go to Settings → Network & internet → Wi-Fi → your network → set the profile to Private.
  • 5Use the same network. The phone must be on the same Wi-Fi SSID — not cellular, and not a guest network that isolates devices from each other.
  • 6Press “Check this address” above. If the PC answers there but the phone still cannot, the block is Windows Firewall or Wi-Fi isolation, not the app.
  • 7Connect banks on the computer. Some banks' sign-in windows do not return cleanly on a phone browser.
